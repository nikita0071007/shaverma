# Моя шаверма — заметки для Claude

Мобильная/веб-игра в духе «Моя кофейня»: игрок готовит шаверму в 3D-шаурмичной с открытой кухней.
Владелец — Никита (GitHub `nikita0071007`), пишет по-русски, не программист. Отвечать по-русски, просто,
без жаргона; делать самому и показывать результат (скриншоты), а не задавать лишних вопросов.

- Режим разработчика: кнопка на стартовом экране или `?dev` → 2 000 000 ₽, бесконечные 💎, все рецепты открыты.

## Как устроено

| Файл | Что внутри |
|---|---|
| `index.html` | Вся игровая логика (IIFE, ES5): день, гости, заказы, рецепты, проверка, деньги, улучшения, магазин 💎, обучение, сохранение (`localStorage` `shaverma-save-v1`), панель-чеклист. Плоский 2D-зал на canvas остался запасным вариантом, если WebGL не поднимется. |
| `js/kitchen.js` | ES-модуль, общая 3D-сцена (Three.js 0.169, `vendor/`): кухня — вертела, мармит на 10 лотков, соусы, напитки, гриль, нож; камера-перелёт между видами `hall`/`kitchen` (+ `hallTall` для вертикального экрана). Экспортирует сцену и хелперы для `hall.js`. API: `window.Kitchen` (`setView`, `roll`, `take`, `reset`, `setOrder`, `setPerks`, `state`). |
| `js/hall.js` | 3D-зал: пол, стены, дверь, столы/стулья, стеклянная витрина, повар в проходе, гости/курьеры, холодильник с напитками, официант, кот, неон, темы стен, пузыри заказов и лента чеков (DOM поверх canvas). |
| `js/sound.js` | Звуки на Web Audio (без файлов) + `Sfx.say()` — голос повара через speechSynthesis. |

- Логика гостей идёт в плоских координатах 640×400; `hall.js` переводит их в 3D: `X=(x-235)*0.0326`, `Z=7.1+(y-100)*0.045`, пол на `y=-3`.
- Связь игры и сцены: `window.Game` (`G`, `select(c)`), `window.onKitchenChange(state)`, событие `kitchenready`.
- Порядок от стены: рабочий стол (вертела → доска → мармит, соусы сзади, гриль за доской, напитки слева) → проход с поваром → стеклянная витрина с кассой → зал.

## Механики (текущее состояние)

- Заказ = рецепт (10 шт., `RECIPES` в `index.html`, открываются по дням) + иногда напиток. Мясо срезается плавно (порция ≈ 55px движения ножа), начинки из лотков, соус, «Завернуть» → гриль (золотистая = +30 ₽, сгорела = ошибка) → «Подать». Лишняя начинка = ошибка.
- Гости ждут ~90 с, день 2,5–4 мин. Курьеры выдуманной службы «Мчим Еда» (оранжевые) раз в 300 с игрового времени. ~35% гостей сами берут бутылку из холодильника (80 ₽).
- Улучшения дня (₽): столики, диванчики, вывеска, холодильник, нож, гриль, кран. Магазин 💎: форма/головной убор/внешность повара, официант, кот, интерьер. 💎: +1 за идеальный заказ, +3 за день.
- Первый день для нового игрока — обучение (один терпеливый гость, время стоит, подсказки + голос).
- Вертел худеет: 12 порций на конус (`G.spit`), пустой — тап по нему ставит новый за 300 ₽. Столы после гостя грязные (`G.dirty`), не заняты, пока не нажать «🧽 Убрать» (официант убирает сам через 5 с).
- Фоновая музыка генерируется в `sound.js` (дарбука + щипковая мелодия в хиджазе), кнопка 🎵.

## Ассеты и лицензии

- `assets/polyhaven/` — CC0 (доска, мебель, лампа, растение, касса, текстуры). Тяжёлые модели упрощены `gltfpack` (`*_lo.gltf`).
- `assets/models/sauce-bottle.glb`, `courier.glb` — Meshy, бесплатный тариф, CC BY 4.0 → в игре строка «3D-модели: Meshy». Курьер без текстуры (тонируется в коде).
- `assets/textures/` — мясо и готовая шаверма из картинок, присланных Никитой.
- `assets/characters/` — анимированные люди Quaternius (CC0, Animated Men/Women, Google Drive → FBX → GLB через FBX2glTF): Walk/Idle/Sitting и др.; гости перекрашиваются по материалам Shirt/Pants/Hair/Skin, официант — Male_Suit. Клонировать через `SkeletonUtils.clone`. Повар пока процедурный (его одежда меняется в магазине).
- Бренды не использовать (была «Яндекс Еда» → заменено на «Мчим Еда»).

## Как проверять (облачная среда)

- Синтаксис: вырезать главный `<script>` из `index.html` в файл и `node --check`; модули копировать в `*.mjs` и `node --check`.
- Браузер: Playwright из скретчпада, `executablePath` = `/opt/pw-browsers/chromium_headless_shell-1194/.../headless_shell`, флаги `--use-angle=swiftshader --enable-unsafe-swiftshader`. Сервер `python3 -m http.server 8765` в корне репо (запускать в той же команде — фоновые процессы умирают).
- 3D в swiftshader очень медленный: ждать `window.Kitchen.progress>=1`, гостей подкладывать через `window.Game.G.cust.push(...)`, обучение отключать `localStorage.setItem('shaverma-tutorial-done','1')`.
- Meshy CLI: `NODE_USE_ENV_PROXY=1 npm exec --yes --package=meshy-cli@0.4.0 -- meshy ...`; создание моделей через API на бесплатном тарифе запрещено, но модели из аккаунта Никиты (ссылки `meshy.ai/s/...`) скачиваются через `text-to-3d get <id>` → `model_urls.glb`.
- Разрешённые домены сети: meshy, polyhaven, quaternius.com, kenney.nl, download.blender.org; Google Drive и github releases тоже открываются; poly.pizza блокирует ботов.
- Godot 4.3 в облаке работает (рендер через `xvfb-run` + `--rendering-driver opengl3`), экспорт под Android не проверялся.
